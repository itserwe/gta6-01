Solmar — an original 2D top-down open-world crime game: a sun-soaked coastal city to explore on foot and by car. Steal cars (E), weave through traffic and pedestrians, raise a wanted level of 1–5 stars with police that chase you on foot and by car, fight back, and play 5 story missions for Riko — from the garage to the harbour heist. HUD with minimap, start screen, save (C to continue), synthesized sounds, no network requests. An entry for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome (or serve game/ from any static server — the game makes no network requests).
